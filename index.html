Introduction aux Sessions PHP

Qu'est-ce qu'une session ?

Une session en PHP est un mécanisme qui permet de conserver des données sur plusieurs pages web pour un même utilisateur. Contrairement aux cookies qui stockent les données sur l'ordinateur du client, les sessions stockent les données sur le serveur.

Pourquoi utiliser les sessions ?

Le protocole HTTP est sans état (stateless), ce qui signifie que chaque requête est indépendante des autres. Sans sessions, le serveur ne pourrait pas savoir si deux requêtes proviennent du même utilisateur. Les sessions permettent de maintenir un état entre les différentes pages visitées.

Utilité des sessions

  • Authentification des utilisateurs : Garder un utilisateur connecté à travers différentes pages
  • Paniers d'achat : Mémoriser les articles sélectionnés par un utilisateur
  • Préférences utilisateur : Enregistrer les choix et paramètres de l'utilisateur
  • Sécurité : Stocker des données sensibles côté serveur plutôt que côté client
  • Statistiques : Suivre le comportement des utilisateurs sur le site

Fonctionnement technique

PHP utilise un identifiant unique (PHPSESSID) pour associer un utilisateur à ses données de session. Cet identifiant est généralement stocké dans un cookie côté client.

Comment fonctionne une session ?

  1. Lorsque session_start() est appelé, PHP vérifie si un cookie de session existe déjà
  2. Si non, PHP génère un nouvel identifiant unique (PHPSESSID) et crée un cookie contenant cet ID
  3. PHP crée également un fichier sur le serveur (généralement dans /tmp) pour stocker les données de session
  4. Lorsque l'utilisateur visite une autre page, le cookie est envoyé avec la requête
  5. PHP utilise l'ID pour retrouver les données de session associées à cet utilisateur

Cycle de vie d'une session

  1. Initialisation : session_start() crée ou récupère une session
  2. Stockage : Les données sont sauvegardées côté serveur
  3. Identification : Un cookie PHPSESSID est envoyé au navigateur
  4. Persistance : Les données restent disponibles jusqu'à la fermeture du navigateur

Fonctions principales :

  • session_start() - Démarre une nouvelle session ou reprend une session existante
  • $_SESSION - Tableau associatif contenant les variables de session
  • session_destroy() - Détruit toutes les données enregistrées dans une session

Sécurité des Sessions

Bonnes pratiques

  • Toujours utiliser session_start() au début du script
  • Régénérer l'ID de session après connexion (session_regenerate_id())
  • Valider les données avant de les stocker dans la session
  • Détruire la session proprement (session_destroy())
  • Définir un délai d'expiration pour les sessions inactives

Exemples pratiques

Exemple pratique : Compteur de visites

Voici un exemple complet de compteur de visites utilisant les sessions PHP :

Code source :
<?php
/*
 * EXEMPLE COMPLET DE GESTION DE SESSION
 * Cet exemple montre comment :
 * 1. Démarrer une session
 * 2. Stocker des données dans la session
 * 3. Persister des informations entre les pages
 */

// 1. DÉMARRAGE DE LA SESSION - Doit être la première instruction
// Crée un fichier temporaire sur le serveur et un cookie PHPSESSID chez le client
session_start();

// 2. INITIALISATION DU COMPTEUR
// Vérifie si la variable de session existe, sinon la crée
if (!isset($_SESSION['visites'])) {
    $_SESSION['visites'] = 0; // Initialisation à 0
    $_SESSION['premiere_visite'] = date('d/m/Y H:i:s'); // Date de première visite
}

// 3. INCÉMENTATION DU COMPTEUR
// À chaque rafraîchissement, le compteur augmente
$_SESSION['visites']++;
// Mise à jour de la dernière visite
$_SESSION['derniere_visite'] = date('d/m/Y H:i:s');
?>

<!DOCTYPE html>
<html>
<head>
    <title>Exemple de Session PHP</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <div class="container">
        <h1>Exemple Pratique de Sessions</h1>
        
        <div class="alert alert-info">
            <p>Nombre de visites : <?php echo $_SESSION['visites']; ?></p>
            <?php if ($_SESSION['visites'] > 1): ?>
                <p>Dernière visite : <?php echo $_SESSION['derniere_visite']; ?></p>
                <p>Première visite : <?php echo $_SESSION['premiere_visite']; ?></p>
            <?php endif; ?>
        </div>
    </div>
</body>
</html>
Explication détaillée
Étapes principales
  1. Démarrage de la session : session_start() doit être appelé avant tout output HTML
  2. Initialisation conditionnelle : Vérifier si la variable existe déjà pour éviter de réinitialiser à chaque visite
  3. Mise à jour des données : Incrémenter le compteur et enregistrer la date
  4. Affichage des données : Utiliser les variables de session pour personnaliser l'interface
Points importants
  • Les données de session persistent entre les rafraîchissements de page
  • Les données sont stockées côté serveur, seul l'ID est envoyé au client
  • Les sessions expirent généralement à la fermeture du navigateur
Note : Pour tester cet exemple, créez un fichier PHP avec ce code et actualisez la page plusieurs fois.

Exemple 2 : Système de connexion simple

<?php
// login.php - Formulaire de connexion et traitement
session_start();

// Vérifier si l'utilisateur est déjà connecté
if (isset($_SESSION['logged_in']) && $_SESSION['logged_in'] === true) {
    header('Location: dashboard.php');
    exit;
}

$error = '';

// Traitement du formulaire de connexion
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    // Vérification des identifiants (exemple simplifié)
    if ($_POST['username'] === 'admin' && $_POST['password'] === 'secret') {
        // Régénère l'ID de session pour la sécurité
        session_regenerate_id(true);
        
        // Stocke les informations de connexion
        $_SESSION['logged_in'] = true;
        $_SESSION['username'] = $_POST['username'];
        $_SESSION['login_time'] = time();
        
        // Redirection vers le tableau de bord
        header('Location: dashboard.php');
        exit;
    } else {
        $error = "Identifiants incorrects";
    }
}
?>

<!DOCTYPE html>
<html>
<head>
    <title>Connexion</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <div class="container">
        <h1>Connexion</h1>
        
        <?php if ($error): ?>
            <div class="alert alert-danger"><?php echo $error; ?></div>
        <?php endif; ?>
        
        <form method="post" action="">
            <div class="mb-3">
                <label for="username" class="form-label">Nom d'utilisateur</label>
                <input type="text" class="form-control" id="username" name="username" required>
            </div>
            <div class="mb-3">
                <label for="password" class="form-label">Mot de passe</label>
                <input type="password" class="form-control" id="password" name="password" required>
            </div>
            <button type="submit" class="btn btn-primary">Se connecter</button>
        </form>
    </div>
</body>
</html>
Explication du système de connexion
Points clés
  1. Vérification préalable : On vérifie si l'utilisateur est déjà connecté pour éviter une reconnexion inutile
  2. Régénération de l'ID : session_regenerate_id(true) crée un nouvel ID de session pour prévenir les attaques de fixation de session
  3. Stockage des informations : On enregistre les données importantes dans la session
  4. Redirection : Après connexion réussie, on redirige vers le tableau de bord
Sécurité

Dans un système réel, vous devriez :

  • Hacher les mots de passe (avec password_hash)
  • Utiliser des requêtes préparées pour la base de données
  • Filtrer et valider toutes les entrées utilisateur

Exemple 3 : Déconnexion sécurisée

<?php
// logout.php - Script de déconnexion
session_start();

// Vider le tableau de session
$_SESSION = array();

// Détruire le cookie de session si présent
if (ini_get("session.use_cookies")) {
    $params = session_get_cookie_params();
    setcookie(session_name(), '', time() - 42000,
        $params["path"], $params["domain"],
        $params["secure"], $params["httponly"]
    );
}

// Détruire la session
session_destroy();

// Rediriger vers la page d'accueil
header('Location: index.php');
exit;
?>
Explication de la déconnexion
Étapes de déconnexion
  1. Vider les données : $_SESSION = array(); supprime toutes les variables de session
  2. Supprimer le cookie : Utilisation de setcookie pour effacer le cookie de session
  3. Détruire la session : session_destroy() supprime le fichier de session sur le serveur
  4. Redirection : Rediriger l'utilisateur vers la page d'accueil
Important : Une déconnexion complète doit supprimer à la fois les données de session et le cookie associé.

Fonctions principales des sessions PHP

Fonction Description Exemple
session_start() Démarre une nouvelle session ou reprend une session existante session_start();
session_destroy() Détruit toutes les données enregistrées dans une session session_destroy();
session_regenerate_id() Remplace l'ID de session actuel par un nouveau session_regenerate_id(true);
session_unset() Libère toutes les variables de session session_unset();
session_id() Récupère ou définit l'ID de session actuel $id = session_id();
session_name() Récupère ou définit le nom de la session actuelle $name = session_name();
session_status() Retourne le statut de la session courante if(session_status() == PHP_SESSION_ACTIVE){...}
